# Codon

A high-performance Python implementation that compiles to native machine code, with native multithreading and seamless Python interoperability.

1.  [Python code](https://docs.exaloop.io/start/usage/)
    
    Write familiar Python, then compile and run it with Codon.
    
2.  [Parsing](https://docs.exaloop.io/developers/compilation/#parsing)
    
    Codon reads Python code and organizes it into a form the compiler can analyze.
    
3.  [Type checking](https://docs.exaloop.io/developers/compilation/#type-checking)
    
    Static type checking and inference enable native code generation, without requiring type annotations.
    
4.  [Codon IR](https://docs.exaloop.io/developers/ir/)
    
    A rich intermediate representation supports compiler analyses, transformations, and optimizations.
    
5.  [Optimization](https://docs.exaloop.io/developers/compilation/#codon-ir-optimization)
    
    General-purpose, Python-specific, and domain-specific optimizations turn high-level code into efficient native programs.
    
6.  [Native code](https://docs.exaloop.io/developers/compilation/#code-generation)
    
    LLVM lowers the optimized program to native machine code for your target hardware.

## Familiar Python. A different runtime.

Codon stays close to Python's syntax and semantics, but it is not a drop-in replacement for CPython. Some dynamic behavior and library interfaces differ. [Python interoperability](https://docs.exaloop.io/integrations/python/python-from-codon/) lets you keep using Python libraries alongside native code.

[Read the compatibility guide](https://docs.exaloop.io/language/overview/#differences-with-python)
